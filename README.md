# posmitny.com

Personal site of André Posmitny: Work, Fun and Me.

- Next.js (App Router) + TypeScript, plain CSS design system in `src/app/globals.css`
- Time-of-day modes (dawn, midday, golden hour, storm, night) in `src/lib/modes.ts` drive both the canvas scene and the site colours
- Copy lives in `src/content/` so Swedish and Spanish can be added later
- Fonts are self-hosted via Fontsource

```bash
npm install
npm run dev
```
